# 基于 STM32 的智能小车

面向大学生电子设计竞赛（电赛）场景的 STM32 智能小车项目。项目以模块化设计为目标，围绕小车运动控制与环境感知，逐步实现循迹、避障、遥控等基础功能，并根据往年赛题和实际任务需求扩展相应功能。

> **项目状态：** 建设中。具体硬件选型、功能实现情况和使用方法将随项目进展持续补充；下文描述的是项目目标，不代表所有功能已完成。

## 项目背景

电子设计竞赛通常要求参赛者在有限时间内完成方案设计、硬件搭建、嵌入式软件开发与系统联调。智能小车具有运动控制、传感器采集和实时决策等典型问题，适合作为竞赛训练与功能验证平台。

本项目计划以 STM32 为控制核心，将底层驱动、传感器数据处理、运动控制和任务逻辑分层组织，便于在基础功能之上快速组合和扩展，适应不同赛题的要求。

## 计划功能

- **循迹：** 获取赛道或引导线信息，控制小车沿预设路径行驶。
- **避障：** 检测行驶方向上的障碍物，并根据任务要求停车或调整行驶方向。
- **遥控：** 接收外部控制指令，实现基本的启停、转向和速度控制。具体遥控方式以实际硬件与程序实现为准。
- **运动控制：** 封装电机控制与运动状态管理，为循迹、避障和遥控等功能提供基础。
- **赛题扩展：** 根据往年题目及当年任务要求，按需增加传感器、执行机构、数据处理和任务流程等功能。

## 设计思路

项目功能可按以下层次逐步实现：

1. **硬件驱动层：** STM32 外设、传感器及执行机构的基础控制与数据采集。
2. **功能模块层：** 电机控制、循迹、避障和遥控等独立功能。
3. **任务逻辑层：** 根据当前模式和赛题要求，组织各功能模块协同工作。
4. **调试验证：** 分模块测试，再进行整车联调，并根据赛道和任务条件调整参数。
